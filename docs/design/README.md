# Design docs

The record of how WEX Business Payments looks, reads, and behaves, so screens (Figma) and code stay consistent.

| File | Holds |
|---|---|
| [decisions.md](decisions.md) | Dated decision log |
| [deviations.md](deviations.md) | Where screens depart from the WEX UI Kit, and what we decided |
| [writing.md](writing.md) | Voice, capitalization, terminology, copy patterns |
| [patterns.md](patterns.md) | Interaction patterns, workflows, behaviors |
| [statuses.md](statuses.md) | Every status: label, meaning, badge token |
| [glossary.md](glossary.md) | Domain terms and definitions |

Entries are **Decided** (confirmed) or **Proposed** (suggested, not yet confirmed). Only decided entries are binding.
