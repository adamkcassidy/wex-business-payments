# UI writing

## Voice

Not decided yet.

**Open:** reconcile the Proposed entries below with the WEX brand writing guide (private reference). The guide differs on three points:
- It bans contractions.
- It spells out dates in sentences.
- It capitalizes page and tab names when text refers to them.

Decide where the product follows the guide and where it intentionally differs.

## Mechanics

- **Proposed:** sentence case for every label, button, heading and menu item ("Issue virtual card", not "Issue Virtual Card").
- **Proposed:** buttons start with a verb and name the result ("Issue card", "Export CSV"). Avoid "Submit" and "OK".
- **Proposed:** money is shown with its currency symbol and two decimals, using tabular numerals in tables (`$1,250.00`).
- **Proposed:** dates in tables use `Nov 17, 2026`, with relative time ("2 hours ago") only for activity feeds.

## Copy patterns

- **Proposed:** an empty state says what goes there and offers one action ("No cards yet. Issue your first virtual card.").
- **Proposed:** an error explains what happened and what to do next, and appears next to its field.
- **Proposed:** a destructive confirmation names the object and the consequence ("Cancel card ending 4821? This can't be undone.").

## Terminology

Use the terms in [glossary.md](glossary.md) exactly. Don't use synonyms (for example, don't mix "card" and "account").
